The AI Diet Planner is a web-based application that generates a basic diet plan based on user inputs like age, height, weight, and fitness goal.
It features a modern glassmorphism UI designed using HTML and CSS for a clean and attractive look.
JavaScript is used to collect user data and send it to the backend using the Fetch API.
The backend is built with Python Flask, which processes the data and returns a diet recommendation.
The application demonstrates simple frontend and backend integration.
It is beginner-friendly and suitable for academic or portfolio projects.
This project helps understand API communication, UI design, and basic health-based logic.
